# Vehicle Weapons (7 Days to Die V3.4)

Craftable helicopter (twin turbines, tail rotor, hover flight) and vehicle weapon mods for the 4x4 truck, gyrocopter
and helicopter: swivel machine gun, rocket launcher and bomb bay. Singleplayer.

**Download:** the ZIP under [Releases](../../releases) (requires 7 Days to Die V3.4). License: MIT (see `LICENSE`).

## Install
1. Copy the folder `VehicleWeapons` into `<7 Days To Die>\Mods\` (create `Mods` if it does not exist).
2. **Start the game without EAC** (Easy Anti-Cheat): start Steam, then run `7DaysToDie.exe` directly from the game
   folder — not the Play button in Steam, which starts `7DaysToDie_EAC.exe`. With EAC the mod is skipped.
3. **Never load a save that contains mod items with EAC on** — the game saves the player without them and the
   player file cannot be loaded afterwards. Back up your save before trying the mod.

## Use
- Craft the **Helicopter Turbine Kit** (Vehicles skill 100) and build the helicopter at the workbench from the
  gyrocopter parts + turbine kit. Weapon mods: machine gun (Machine Guns 61), bomb bay (Explosives 35), rocket
  launcher (Explosives 50). The 4x4 truck takes the machine gun *or* the rocket launcher.
- Install the weapon mods like other vehicle mods. Put the ammo into the **vehicle storage**: 7.62mm, HE/frag rockets,
  pipe bombs, grenades, contact grenades, dynamite, molotovs.
- Left mouse = machine gun, right mouse = rocket / bomb, middle mouse = switch type. While driving, the mouse aims
  and A/D steers. Helicopter: Space up, C down, W/S forward/back, A/D turn, Shift faster.
- Console (F1) for testing: `testpacket` (vehicles, mods, fuel, ammo), `testskills` (unlocks the recipes).

All models, textures and icons are original work; the M60 on the truck mount is the game's own model, loaded at
runtime from your installation.

# Vehicle Weapons (deutsch)

Baubarer Hubschrauber (zwei Turbinen, Heckrotor, Schwebeflug) und Waffen-Mods für 4x4-Truck, Tragschrauber und
Hubschrauber: schwenkbares MG, Raketenwerfer und Bombenschacht. Einzelspieler.

## Installation
1. Den Ordner `VehicleWeapons` nach `<7 Days To Die>\Mods\` kopieren (`Mods` ggf. anlegen).
2. **Spiel ohne EAC starten:** Steam starten, dann `7DaysToDie.exe` direkt aus dem Spielordner starten — nicht über
   „Spielen“ in Steam (das startet `7DaysToDie_EAC.exe`). Mit EAC wird der Mod übersprungen.
3. **Einen Spielstand mit Mod-Gegenständen nie mit EAC laden** — der Spieler wird dann ohne sie gespeichert und lässt
   sich danach nicht mehr laden. Vorher den Spielstand sichern.

## Benutzung
- **Hubschrauber-Turbinensatz** bauen (Fertigkeit Fahrzeuge 100), dann den Hubschrauber an der Werkbank aus den
  Tragschrauber-Teilen + Turbinensatz. Waffen-Mods: MG (Maschinengewehre 61), Bombenschacht (Sprengstoffe 35),
  Raketenwerfer (Sprengstoffe 50). Der 4x4-Truck nimmt MG *oder* Raketenwerfer.
- Einbauen wie andere Fahrzeug-Mods. Munition ins **Fahrzeuglager**: 7,62 mm, HE-/Frag-Raketen, Rohrbomben,
  Granaten, Aufschlagzünder, Dynamit, Molotows.
- Linke Maustaste = MG, rechte = Rakete/Bombe, mittlere = Sorte wechseln. Am Steuer zielt die Maus, A/D lenkt.
  Hubschrauber: Leertaste steigen, C sinken, W/S vor/zurück, A/D drehen, Shift schneller.
- Konsole (F1) zum Testen: `testpacket` (Fahrzeuge, Mods, Benzin, Munition), `testskills` (schaltet die Rezepte frei).
